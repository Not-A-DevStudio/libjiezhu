Detailed Description

Runtime monkey-patches that prepend the jiezhu prompt prefix to OpenAI ChatCompletion and Anthropic Messages requests.

The module exposes :func:install, :func:uninstall, :func:set_prefix and :func:get_prefix and stores its global configuration and the original (pre-patch) callables in module-level singletons.

Install monkey-patches for the OpenAI and Anthropic SDKs.

The function intercepts the messages argument of the OpenAI Completions.create (and AsyncCompletions.create) callables and the system argument of the Anthropic Messages.create (and AsyncMessages.create) callables, prepending prefix_text to the system prompt. When a modification happens, the change is printed to output and, unless :attr:require_confirm is False, the user is prompted for confirmation.

The function is idempotent: calling it twice is a no-op as long as :func:uninstall has not been called in between.

Parameters
prefix_textPrefix to prepend. Defaults to :data:DEFAULT_PROMPT_PREFIX. Ignored when None.
require_confirmWhen True (default), prompt the user on output before applying the modification.
max_preview_charsMaximum number of characters of prefix_text shown in the confirmation prompt.
input_fnReplacement for :func:input used to read the y/N answer. Mainly intended for tests.
outputReplacement for :data:sys.stderr used to display the confirmation prompt. Mainly intended for tests. @raise RuntimeError If openai is not importable or no patch target is found in the installed SDK version.
