Detailed Description

Thin HTTP client for OpenAI / Anthropic chat-completion APIs.

Wraps libcurl and exposes a small set of request helpers for the "pure" (no prompt modification) and "jiezhu" (prefix-injection) flows in both blocking and SSE-streaming variants.

Stream an OpenAI-style chat-completion response as server-sent events.

OpenAI-style SSE streaming chat-completion call.

The request is mutated to set stream = true, then POSTed to {base_url}/chat/completions. The on_event callback is invoked for each parsed SSE event.

Parameters
requestRequest payload. Will have stream set to true.
on_eventCallback invoked for every parsed SSE event. Returning false aborts the stream.
Exceptions
std::runtime_errorOn transport / HTTP failure.

Sets request.stream = true, POSTs the request to {base_url}/chat/completions and forwards each parsed SSE event to on_event. The transfer is aborted (politely) if the callback returns false or once the [DONE] sentinel is seen.

Parameters
requestThe request payload (will be copied and mutated).
on_eventPer-event callback. Returning false cancels the stream.
Exceptions
std::runtime_errorOn transport / HTTP failure.
