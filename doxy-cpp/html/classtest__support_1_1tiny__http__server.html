Detailed Description

A single-threaded, loopback-only HTTP/1.1 test server.

The server binds to an ephemeral port on 127.0.0.1, accepts connections one at a time, hands the raw request bytes to a user-supplied handler, and writes the handler's response back. The most recently received request can be retrieved with last_request() for assertion purposes.
