Detailed Description

Public chat-completions API for the jiezhu C++ SDK.

Defines the request/response value types and the jie::client used to talk to OpenAI-compatible and Anthropic Claude chat-completion endpoints, including the optional "jiezhu" (blessing) prompt-injection variants that prepend an empathetic Chinese system prompt.
