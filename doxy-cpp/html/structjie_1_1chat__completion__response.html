Detailed Description

Response payload returned by a chat-completion call.

Stores the raw JSON returned by the server together with a few convenience accessors for the most common fields. A best-effort helper first_content() normalizes the most frequent response shapes (OpenAI and Anthropic).

std::string jie::chat_completion_response::first_content ( ) const

Extract the text of the first assistant message.

Best-effort extraction of the assistant's first text payload.

Supports both the OpenAI shape (choices[0].message.content) and the Anthropic shape (content[0].text). Returns an empty string if neither pattern is recognized.

Returns
Concatenated text, or empty string when unavailable.

Tries the OpenAI shape (choices[0].message.content) first and then the Anthropic shape (content[0].text). Returns an empty string if neither pattern is matched.

Returns
The extracted text, or an empty string when unavailable.
