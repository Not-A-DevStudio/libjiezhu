Detailed Description

Single-threaded loopback HTTP server used by the Catch2 tests.

Provides a RAII helper that binds to an ephemeral port on the loopback interface, dispatches incoming connections to a user-supplied handler and exposes the captured request for assertions. The class is intentionally minimal — it is not intended for production use.
