std::string jie::response_response::first_content ( ) const

Extract the text of the first output item.

Best-effort extraction of the first output text from a Responses API response.

Supports both the structured format (output[0].content[*].text) and the convenience field (output_text). Returns an empty string if neither pattern is recognized.

Tries the structured format (output[0].content[*].text) first and then the convenience field (output_text). Returns empty string when unavailable.

Returns
The extracted text, or an empty string when unavailable.
